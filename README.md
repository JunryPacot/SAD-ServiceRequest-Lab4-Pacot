# SAD-ServiceRequest-Pacot - Laboratory 4

## Role-Based Asset Transaction and Approval Management

This project upgrades the Laboratory Asset and Service Management System with role-based access, borrowing approval, business-rule validation, maintenance processing, and audit logging.

### Technologies
- HTML5
- CSS3
- JavaScript
- Supabase PostgreSQL
- Supabase Authentication
- GitHub Pages

### User Roles
- Administrator
- Laboratory Staff
- Requester / Viewer

### Main Modules
- Dashboard
- Equipment
- Borrowing Requests
- Maintenance
- User Role Management
- Audit Logs
